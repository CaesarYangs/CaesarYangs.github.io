# Paperbox 简化版设计

用户在查看第一版后要求参考 https://jinyansu1.github.io/blog/2026/09/my-phd-grind-1/ ，降低页面复杂度。

参考网站的公开仓库中，文章模板采用白底、900px 单栏正文、简单顶栏、蓝色链接及标题下的日期。当前版本按这些排版特征实现，不复制对方文章内容。

首页是简介和文章列表；文章页保留标题、日期、正文与返回链接。去掉纸张插画、卡片、搜索弹窗、搜索索引和侧栏目录。

保持纯 HTML/CSS/JavaScript，直接部署到 GitHub Pages，不需要构建。17 篇正文及 50 个旧地址保留；博客仅清理 Hugo 生成的重复标题与元数据前言。代码、图片 URL、正文锚点和公式继续保留。

验证：内容保全、全部本地链接、320/390/768/1024px 布局、禁用 JavaScript 的全部文章阅读、公式显示，以及桌面/手机截图。
